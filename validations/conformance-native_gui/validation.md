# 原版 GUI 控件验收

## 目标

在参考端使用固定 MCP 快照验证 GLASS 标准控件的真实语义读取、鼠标与键盘操作、频道和无线节点选择、设置保存与重新打开。无线空间预览的绘制内容不要求结构化读取，其外围按钮仍需可操作。其他 Target 通过对应编译、测试与发行检查，不据此宣称游戏运行验收。

## 运行

从仓库根目录执行。源世界是本项目混合展示场景，须先正常保存并关闭；工具只复制它，不修改源实例。每次自动验证使用新的专用实例与结果目录，正常 Loader 安装与固定快照沿用 MCP 接入验证。测试不加载项目探针，因此没有 `[instances]` 开发运行。

```powershell
.\gradlew.bat check verifyRelease
.\gradlew.bat :runtime_validation:verifyNativeGui
```

通过后运行下面的命令，将已验证世界复制为独立体验实例，使用当前发行 JAR 与用户验收预设，并释放 MCP 控制。

```powershell
.\gradlew.bat :runtime_validation:launchGuiAcceptance
```

本地 MCP 输入和正常 Loader 安装须已按 [MCP 接入验证](../integration-mcp_alpha/validation.md) 准备。自动测试为 Vulkan、1920×1080、全局静音；验收实例为 2560×1440、全局声音 50%、音乐关闭、玩家 RecRivenVI，按项目已登记输入安装 Custom Skin Loader。Zume 无精确匹配版本则跳过。

## 通过标准

MCP UI 树提供频道和节点的独立条目、真实名称、坐标、选择和可操作状态，不依靠截图或预先计算的行号选择。终端文本和可见性修改后保存重开一致；Tab 移动焦点而不改变值。无线绑定、节点移动与保存结果可回读。配置页可读取当前值，真实修改后保存重开一致，并恢复测试前设置。键盘导航不截获其他控件的焦点。

记录实际 UI 树、操作和截图；自动实例正常保存退出。运行失败即任务失败，报告不以输入管线完成代替效果验证。体验实例只在自动验证通过后启动，交接为 READ 且输入已释放。数据限制和快照边界沿用项目规范。

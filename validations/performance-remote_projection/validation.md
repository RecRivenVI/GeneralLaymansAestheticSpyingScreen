# 远端投影性能测量

## 目标

测量 1.21.1 NeoForge 统一路线 B 的客户端、服务端和网络成本。对照不开投影与检查点 35f1fc0 的路线 A，覆盖 0、1、2、4 个网络、Sodium、远端、下界与移动子世界。只测量与归因，不修改产品实现或预算。

## 运行

从仓库根目录执行：

```powershell
.\gradlew.bat :version:1.21.1-neoforge:probeJar
.\gradlew.bat :runtime_validation:measureRemoteProjection
```

先完成最小配对样本与探针开销核对，再扩大测量。自动客户端静音，窗口为 1920×1080。并行 GPU 进程逐窗记录，不关闭用户客户端。原始分帧数据及窗口摘要写入本验证的结果目录。

命令会复用本轮已经正常退出的冻结测量并重新汇总，不把汇总称为新测量。测量新候选时应先通过项目回收工具迁出已有运行，保留上一份交付；不把不同候选的窗口混在一起。

## 通过标准

实际场景与网络数符合请求，输出帧时间分位数、捕获与绘制的渲染线程及 GPU 计时、编译工作量、内存和显存采样、服务端 MSPT 与字节速率。A/B 至少按 ABBA 交错配对，干扰与无法测量的指标明确标注；数据不足时不推断性能结论。

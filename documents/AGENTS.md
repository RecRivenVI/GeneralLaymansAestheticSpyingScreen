## 补充规则

- **X-01** [判断] 本项目是旧 port GLASS，版本保持 `8.0.0-alpha.1`。不操作 Second Implementation、上游仓库或共享模板。
- **X-02** [判断] 本轮仅迁移构建与源码位置、适配游戏与加载器 API。历史审计缺陷留待下一轮，不以迁移顺便修复。
- **X-03** [判断] 本轮禁止 Computer-Use，不推送，不提交迁移改动。用户实例和历史证据完整保留，清理只送 Windows 回收站。
- **X-04** [判断] 自动测试客户端使用 Vulkan、1920×1080 和关闭全局声音；测试数据软限制 3 GiB、硬限制 5 GiB。
- **X-05** [判断] 构建、单元测试、Profile 与历史 PASS 均不替代本轮游戏及用户视觉验收。S1、S2、M1、M2 独立，分别启动不代表 parity。
- **X-06** [判断] 旧身份日常世界仅作原数据迁移，不转换存档身份；本轮参考端使用独立的新世界。`build/migration-20260909` 含不可重建材料，未经用户决定不得清理。
- **X-07** [判断] 用户已确认本轮补齐三个旧端的完整 GLASS 功能；五端均以真实产品构建验收，不以空项目或 planned 状态代替。
- **X-08** [判断] 用户验收实例使用 2560×1440、全局声音 50%、音乐关闭、玩家名 RecRivenVI；Custom Skin Loader 与 Zume 仅从 Modrinth 精确匹配 Minecraft 与 Loader，没有对应版本时跳过。
- **X-09** [判断] MCP alpha 仅使用已登记的固定分发快照，复制到本项目产物目录后校验 JAR 与手册哈希及 packagedRuntimeVerified；不修改或构建 MCP 仓库。先完成只装 MCP 的最小 READ，再在本项目验证实例操作参考端；端口为 0，从实例端点发现并锁定身份。缺陷仅记录供用户转交。
- **X-10** [判断] 用户另行授权 GUI 标准化：无线空间预览保留自绘，其他控件复用原版结构、交互和焦点，保留 GLASS 主题。参考端由 MCP 实际操作验收后移植其余端，并留下用户体验实例；不修改 MCP 或增加产品对 MCP 的依赖。

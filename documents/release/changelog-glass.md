# 更新日志

适用于 Minecraft 1.20.1、1.21.1、26.1.2 与 26.3 的 GLASS 开发版本。日志按 Keep a Changelog 组织。

## [未发布]

### 新增

- 1.21.1 NeoForge 接入有界独立世界，支持同维度远端和下界的终端画面，提供可配置的传输与强加载预算。
- 1.21.1 NeoForge 适配 Sable 的完整姿态、装配关系与卸载恢复，并支持 Sodium 的独立区块绘制路径。

### 变更

- 五端恢复完整玻璃与黑曜石方块，以及信标、水晶和终端朝向标记；投影在实体阶段之后使用原生深度偏移覆盖，方块面完整保留。
- 两种动画保持开发检查点；可选动画命名为“经典”，修正其提示文字，明确与默认缩放动画的区别。
- GUI 选择列表采用原版条目、滚动和焦点机制，保留 GLASS 主题；终端使用原版可见性切换控件，Tab 恢复为焦点导航。
- 频道与无线节点提供完整的条目朗读文本，设置页沿用原版滑块和布尔控件。
- 迁移到 2.0.2 构建规范，五个 Target 使用独立的原生源码与加载器构建。
- 26.2 Fabric 实现迁移至 26.3，并适配 RenderPearl、SDL 与加载器事件。
- 历史实例、存档和审计记录保留，迁移验收进行中。

### 修复

- 修正 1.20.1 Forge 与 1.21.1 NeoForge 的无线扩展合成配方格式。

- 五端出口裁切固定边界余量，准确捕获 NeoForge 区块模型数据构造器，保留紧贴出口的方块正面。

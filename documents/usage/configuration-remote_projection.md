# 远端投影配置

适用于 Minecraft 1.21.1 NeoForge。投影方块会在观看时自动请求终端附近的画面，支持同维度远端、下界，以及安装 Sable 后的子世界；其他 Minecraft 版本仍使用已加载区域的画面。

## 观看与首次加载

每位玩家同时订阅一个终端，选择观察范围内最近的投影网络。同终端的网络共享数据。首次观看通常需要约六秒取得 25 个源区块，生成新区块时还会增加等待；源跨区块移动时，新数据到齐前保留上一帧。转身离开、关闭供电、失去权限或断开连接会释放订阅。

源画面有范围限制。子世界图块也占用同一份区块名额，会减少最外围的普通世界区块；范围外显示空背景。这里的范围不等于玩家自己的渲染距离。

## 服务端预算

在服务端或单人实例的 `config/glass_remote.json` 中修改，重启生效。下表是试验默认值，尚未由用户确定最终预算。

| 键 | 默认值 | 含义 |
| --- | --- | --- |
| `radius` | 2 | 源所在区块周围的订阅半径，允许 0 至 2 |
| `maxSourceChunks` | 25 | 每个源最多传输的区块数，包含子世界图块，允许 1 至 25 |
| `globalChunks` | 100 | 全服 GLASS 票据实际维持的 FULL 区块与子世界图块的唯一位置总数 |
| `bytesPerSecond` | 524288 | 每位观看者每秒的数据包字节预算 |
| `initialChunksPerSecond` | 4 | 每秒首次区块快照数量 |
| `idleTicks` | 60 | 观看心跳消失后的最长保留时间 |
| `refreshTicks` | 100 | 完成一轮源光照刷新的目标间隔 |
| `maxEntities` | 256 | 每个源最多同步的实体数 |

原版为推进源内实体需要加载邻域：默认的 25 个订阅名额，对应 81 个普通 FULL 区块；一个或两个子世界图块的场景分别计作 82、83 个实际加载位置。重叠位置只计一次，相同终端的观看者共用票据。默认全服 100 的预算偏保守，相距较远的第二个源可能被拒绝；界面会提示预算不足。

## 可选模组

Sable 与 Sodium 的精确兼容发行见[依赖说明](../reference/dependency-runtime.md)。Sable 保留真实世界内容，终端与投影方块可以独立平移和旋转。暂不提供 Iris 适配。

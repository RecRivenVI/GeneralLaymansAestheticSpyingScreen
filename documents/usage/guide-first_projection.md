# 安装与首次投影

适用于 Minecraft 1.20.1 Forge、1.21.1 NeoForge、26.1.2 NeoForge、26.3 NeoForge 与 26.3 Fabric。当前为开发中的 8.0.0-alpha.1，迁移验收尚未完成。

你可以用终端设置画面源，再由投影器显示远处的实时画面。客户端和服务端都需要安装相同版本的 GLASS，以及对应版本的加载器；Fabric 还需要 Fabric API。

## 使用

在创造模式的红石方块分类取得终端、投影器、扩展与无线扩展。右键终端创建或选择频道；右键投影器选择频道，再给投影器供电。连接扩展可组成更大的有线显示面；绑定并排序至少三个无线扩展可组成显示区域。

终端所在区块必须已加载，并与客户端处于同一维度。跨维度显示与旧版本存档身份转换尚未实现。旧端移植及视觉效果仍需验收，不应直接用重要存档测试。

无线扩展可由扩展与末地水晶无序合成。

## 配置

Fabric 通过 Mod Menu，NeoForge 与 Forge 通过模组列表中的配置入口打开 GLASS 设置，可调整画面距离、传播限制、传播延迟与动画。各项默认值由当前发行版本提供。

频道、投影器和无线节点列表支持原版的焦点导航：Tab 切换控件，方向键移动列表选择。频道与投影器列表中，Enter 确认当前条目。终端的公开或私有状态使用独立的切换控件，Tab 不改变其值。无线节点列表选中节点后可用上移、下移和删除调整顺序，保存后生效；空间预览保留独立的拖动与缩放操作。

## 外观、动画与裁切

上述五个版本的投影器、扩展和无线扩展恢复完整的玻璃方块，终端恢复完整的黑曜石方块，并显示内部信标、水晶和朝向标记。默认动画只缩放，不淡入淡出。可选动画称为“经典”：它来自上游，面不缩放；开启时，面先变成纯白，投影画面在白底上淡入；关闭时，投影画面直接消失，然后白底淡出。所有版本都保留原生方块面与正常深度遮挡。

修正了紧贴终端出口的方块面被错误遮蔽的问题；与出口相隔一纹素的面也会保留。跨维度和超过客户端加载范围的终端仍不可用。

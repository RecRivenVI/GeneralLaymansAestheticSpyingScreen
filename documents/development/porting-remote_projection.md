# 远端投影移植说明

本轮只在 1.21.1 NeoForge 接入独立世界；其他四端保持路线 A。共享组件只增加不依赖游戏的仿射数学，不共享加载器或 Minecraft 源码。

| 事项 | 1.21.1 NeoForge 的处理 |
| --- | --- |
| 原生协议 | 绑定当前注册表的 `GameProtocols.CLIENTBOUND_TEMPLATE`，只转发视觉数据包 |
| 独立世界派发 | 复用连接的原生数据包处理器，在上下文中改变字段读取，不改写玩家世界与连接 |
| 合并回调 | Mixin 的选择器不包含已合并处理器；在客户端派发器合并后处理其世界字段读取 |
| 原版区段 | 后台定位使用捕获相机，不能使用玩家的实际坐标 |
| Sodium 区段 | 采用 Sodium 的独立分派器，补齐有界域之外的空邻接单元 |
| Sodium 快照 | `LevelSlice` 按实际世界应用原有终端捕获可见性规则，不依赖网格线程之外的临时上下文 |
| Sodium 粒子 | 独立视图使用已有的原版顶点提交分支，普通视图与地形快速路径保留 |
| 原生重载 | 粒子创建和快速写入转换入口都指定完整描述符，避免只匹配另一个重载 |
| 光照贴图 | 源上下文提供贴图，捕获结束恢复玩家绑定；地形阶段的内饰实体层提交后也恢复当前绑定 |
| 编译缓冲 | 沿用路线 A 的每个派发器独立缓冲，防止共享池饥饿 |
| Sable 姿态 | 完整双精度 `renderPose`，包含旋转中心、缩放以及两端组合产生的剪切 |
| Sable 生命周期 | 原生装配监听保留频道；原生保存指针变化时更新世界级链接，卸载后按 UUID 恢复 |
| 可选类加载 | 稳定客户端入口不引用 Sable 类型；检测到模组后才加载原生适配类 |
| 方块实体动画 | 完整区块只用于首次快照；持续更新不重建方块实体 |

运行验证见[独立投影验证](../../validations/integration-remote_projection/validation.md)。固定候选的视觉结论和差异记录在交付报告；构建通过不代替看图。

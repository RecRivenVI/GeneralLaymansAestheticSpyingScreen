# 当前渲染体验清单

49 号路线 A 在参考端 26.3 NeoForge 提供独立验收实例。启动后保持运行；后续路线 B 使用另一个隔离实例。验收实例使用 2560×1440、RecRivenVI、全局声音 50%、音乐关闭和精确版本 Custom Skin Loader；Modrinth 没有对应 Zume 时跳过。自动截图不代替用户体验。

## 一次完成的体验步骤

1. 初始位置是北向有线面；沿面走动、转动视角，观察完整玻璃方块上的画面，应稳定覆盖，无闪烁或方块面盖住画面。
2. 分别传送至六个朝向的观察点：下 `1280.5 72.88 0.5 0 -90`，上 `1328.5 84.88 0.5 0 90`，北 `1376.5 78.88 -5.5 0 0`，南 `1424.5 78.88 6.5 180 0`，西 `1466.5 78.88 -63.5 -90 0`，东 `1526.5 78.88 64.5 90 0`。命令格式为 `/tp @s` 加上述坐标与视角。
3. 在北向面前放金块和玻璃：金块应挡住投影，玻璃边框可见且中间透出画面。走到侧面观察，保留正常遮挡。
4. 传送至无线面 `/tp @s 1760.5 78.88 -5.5 0 0`：三角区域画面连续，区域外仍可见完整玻璃和转动水晶。
5. 在设置中切换默认与“经典”，开关投影器电源：默认按传播顺序缩放；经典面不缩放，开启先白再显现画面，关闭先消失画面再退去白底。
6. 传送至两个裁切场景 `/tp @s 1664.5 78.88 -5.5 0 0` 和 `/tp @s 1712.5 78.88 -5.5 0 0`：贴面及相隔一纹素的出口应完整，没有中央空洞。
7. 使用 F3+X 切换“改进透明显示”，重复观察有线、无线和前景遮挡；两档都应成立。观察普通玻璃、黑曜石与 GLASS 方块在白天、夜晚、火把旁和阴影中的亮度变化。

## 验收范围

自动对照覆盖六朝向 6–16 格、相对法线 0–80°；东西向额外检查 64 格。更远的另外四向被测试台遮挡，无法比较。地毯、单层雪和火把在本轮掠射样本可见，但更贴面的自定义模型与任意远距离尚未保证。用户可记录范围之外的表现供后续决定。

# 上游行为参考

本文记录独立实现需要理解的原始 GLASS 行为语义。上游仓库、提交和 iChunUtil 仅为只读参考，不定义当前项目身份、Target 状态或现代内部架构。

参考来源：

- GLASS 原仓库：`https://github.com/iChun/GeneralLaymansAestheticSpyingScreen`；
- GLASS 参考提交：`99d9b4170a64d3692b46100d9d3e63cb41c735ee`；
- iChunUtil 参考版本：`1.12.2-7.1.3`。

## 对象与频道

- Terminal 保存频道和六向观察面，是远端观察平面的锚点；
- Projector 保存频道、放置面、红石活动状态和无线顺序；
- Extension 扩展普通显示表面；Wireless Extension 按用户顺序形成三角带；
- 频道区分公开与玩家私有范围；现代服务端必须重新验证权限、距离、方块角色、区块状态和列表长度，不能信任客户端负载。

## 平面与无线传播

上游普通投影从 Projector 的显示面开始，以两 tick 一步向相邻表面传播，并在凹角或凸角上产生新的活动面。当前实现保留延迟传播和面级拓扑，但采用明确的外露面图：从 Projector 正面作为种子，允许沿共边相邻外露面传播，永不进入相贴 GLASS 方块之间的内部面。

无线模式把 Projector 作为三角带首顶点，排序后的 Wireless Extension 作为后续顶点；节点顺序决定几何。无线显示使用一个实时投影源，不得用静帧替代。

邻居变化、方块状态变化、红石变化以及相关区块加载或卸载都会使拓扑失效。现代实现把同一服务端 tick 内的通知合并后重算，客户端再根据新旧面集合播放传播，不把重算表现成无过渡瞬切。

## 相机与实时世界

远端相机不是固定在 Terminal 上。其核心关系为：

1. 取得观察相机相对 Projector 平面中心的位置；
2. 用源平面到目标平面的旋转变换该偏移；
3. 把结果加到 Terminal 后方的目标平面中心；
4. 用同一旋转变换相机完整朝向；
5. 只在显示几何覆盖的屏幕区域呈现目标世界。

因此玩家横移会产生与真实窗户一致的视差。把一张固定 UV 纹理铺到方块上会丢失该语义。上下方向必须使用稳定的六向旋转表示，不能依赖会在正上或正下失去唯一 yaw 的欧拉角组合。

每个活动频道维护独立远端捕获生命周期、区块提取状态、遮挡图和深度目标。捕获内容包括天空、区块、实体、方块实体、粒子、天气、云和世界边界；捕获 GLASS 时禁止递归观察自身。

## 裁切、遮挡与合成

目标端出口平面裁切移除 Terminal 平面背后的世界内容。显示面在主世界深度中参与测试并写入自身深度，使真实遮挡关系保持一致。Vulkan 路径使用独立远端 RenderTarget、投影采样和斜近裁剪实现上游模板区域重绘的可观察结果，而不复制旧 OpenGL 状态机。

## 动画与声音

上游启停传播为两 tick 一步，单面使用十二 tick 白色遮罩。遮罩透明度按剩余时间比例的平方根变化：开启时白色覆盖真实投影后揭开，关闭时白色面逐渐消失。当前项目允许通过配置在该行为与中央缩放动画之间切换；两种模式都必须持续显示真实捕获，并正确处理传播、反向和频道热切换。

活动频道循环播放 `amb.ogg`。环境声跟随最近显示表面，音量和音高保持低而稳定。Projector 与 Wireless Extension 的可视标记随活动状态变化，但其现代模型可以独立设计。

## 允许的现代差异

- 独立维护的 GUI、模型、配置结构和渲染内部实现；
- 更严格的服务端校验和多人同步；
- Loader-first 多版本 Target；
- 精确四元数六向相机、现代 Vulkan 资源管理与职责拆分；
- 在保持实时画面、传播和玩家可观察语义前提下提供可配置动画。

这些差异不能改变公开 mod ID、资源命名空间、必要存档兼容标识、许可或原始归属。

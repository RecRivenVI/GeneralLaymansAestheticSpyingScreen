# 外部模组兼容策略

GLASS 不要求任何其他模组为兼容本模组而重新编译、替换或发布修改版。

兼容代码必须满足：

1. 所有实现都保存在本仓库并由 GLASS 构建；
2. 外部行为接管只能使用本模组注册的 Mixin、事件、反射适配器或公开 API；
3. 可选模组不存在时不得阻止 GLASS 启动；
4. 不复制外部模组源码、资源或修改后的 class 文件；
5. 每个兼容目标放在 `me.ichun.mods.glass.compat.<modid>` 下，Mixin 放在同一目标的专用配置中；
6. 兼容失败必须局限于对应可选功能，不得改变 GLASS 的基础频道、传播和渲染语义。

如果兼容方案必须修改外部模组构建产物、复制其受保护实现，或要求用户安装重新编译版本，该方案不符合项目边界。外部项目只作为行为和公开 API 参考，不能成为 GLASS 的隐藏构建输入。
